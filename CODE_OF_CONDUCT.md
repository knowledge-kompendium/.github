# Code of Conduct

The Knowledge Kompendium adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct for all repositories, issues, discussions, and related spaces.

## Reporting

Report unacceptable behavior to the organization owners at **conduct@knowledge.design**. Reports are handled confidentially, and reporters will not face retaliation.

## Enforcement

The organization owners apply the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban) as appropriate to the behavior reported.
