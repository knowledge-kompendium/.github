# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security problem. Use GitHub's private vulnerability reporting ("Report a vulnerability" on the repository's **Security** tab), or email **security@knowledge.design**.

Include the affected repository and version, a description of the issue, and steps to reproduce. You can expect an acknowledgement within five business days.

## Supported versions

Security fixes are applied to the latest release of each component. Older releases are not maintained unless a repository states otherwise.
