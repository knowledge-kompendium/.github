The Knowledge Kompendium is an open body of specifications, reference implementations, and curated content for **computable, versioned knowledge**: knowledge that can be exchanged, reasoned over, and evolved safely across organizations.

A kompendium compounds rather than merely accumulates. Each contribution is identified, versioned, and attributable, so later work can build on earlier work without guessing what it meant or when it changed.

## Components

| Component | Status | Description |
|---|---|---|
| **ANF** | Active | Analysis Normal Form: a statement-level representation for clinical and terminological assertions, with description-logic semantics for the parts that need them. |

Further components will be added as they mature.

## Principles

- **Identity is stable.** Every component is addressable by a persistent identifier, independent of its label or location.
- **Every change is versioned.** Status, Time, Author, Module, and Path (STAMP) accompany each assertion.
- **Formal semantics where they earn their keep.** Description-logic definitions (EL++ and beyond) are first-class, but not every vertex has to carry them.
- **Specifications and implementations evolve together.** Spec text, reference code, and worked examples live side by side and are released together.
